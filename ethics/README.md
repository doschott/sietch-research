# Ethics

How the project treats the human operator, future participants, and the permission that has been asked of Funcom. The sandbox has no human subjects. The game study is not running.

> **Permission status.** Written permission from Funcom has been requested and is pending. A follow-up was sent on 24 September 2026 (support ticket #308630). No agent will play in Dune: Awakening until a written answer is received. If the answer is no, the agents stay out. If the answer is yes with conditions, those conditions are followed. This project is not affiliated with, sponsored by, or endorsed by Funcom.

## What is in force now

- A human operator is required for every sandbox session the runner will start. See [oversight.md](oversight.md) and [../methodology/supervision.md](../methodology/supervision.md).
- The runner cannot connect to the game. See [../safety/boundaries.md](../safety/boundaries.md).
- Sandbox logs reject personal-data field names. See [../methodology/data-handling.md](../methodology/data-handling.md).
- Contributors follow [../CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md). Reports of harassment go to doschott@gmail.com, as that file already says.
- Public writeups of the game study, if any are ever drafted, are covered by the offer of a first look to Funcom before publication.

## What is not settled

The request does not specify consent, briefing, compensation, or ethics-board review for people on the battlegroup. [consent.md](consent.md) is a proposal. It is pending Funcom review, and it is inactive until a written answer allows people and agents to share a session.

Whether institutional review or another ethics review is required is an open question. This repository does not claim that a board has approved the work.
